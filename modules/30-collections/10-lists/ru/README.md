В этом уроке мы изучим списки Kotlin. Разберём доступ по индексу, изменение содержимого и работу с общими ссылками. Научимся выбирать тип списка по разрешённым операциям.

Список хранит элементы в определённом порядке. У каждого элемента есть индекс, начиная с нуля. Повторяющиеся значения допустимы, а число элементов хранится в свойстве `size`. В типе `List<String>` слово `List` обозначает список, а `String` в угловых скобках задаёт тип его элементов.

Kotlin разделяет доступ к списку на чтение и изменение. Тип `List<T>` предоставляет чтение элементов. Тип `MutableList<T>` дополнительно предоставляет изменение элементов, добавление и удаление. Вместо `T` в конкретном объявлении указывается нужный тип, например `Int` или `String`.

## Чтение элементов

Для маршрута доставки задан список остановок. Их порядок определяет последовательность посещения.

```kotlin
fun main() {
    val stops: List<String> = listOf("Depot", "Library", "Station")
    println(stops.size) // 3
    println(stops[0]) // Depot
    println(stops.getOrNull(2)) // Station
    println(stops.getOrNull(3)) // null
}
```

Запись `stops[index]` читает элемент по индексу. Индекс должен быть неотрицательным и меньше `size`. Выход за границу завершит обращение ошибкой. Метод `getOrNull(index)` возвращает `null` для любого отсутствующего индекса, включая отрицательный.

Для пустого списка тип элементов задаётся в объявлении. Его можно записать как `val stops: List<String> = listOf()`. У него `size` равно нулю и нет допустимого индекса.

## Изменение списка

Когда маршрут редактируют, нужен `MutableList`. Функция `mutableListOf()` создаёт такой список.

```kotlin
fun main() {
    val stops = mutableListOf("Depot", "Library")
    stops[1] = "Museum"
    stops.add("Station")
    val removed = stops.removeAt(0)
    println(removed) // Depot
    println(stops) // [Museum, Station]
}
```

`add()` добавляет элемент в конец. `removeAt()` удаляет элемент по индексу и возвращает его прежнее значение. После удаления индексы следующих элементов сдвигаются. Присваивание `stops[1] = ...` меняет существующий элемент и не увеличивает размер.

`val` запрещает присвоить переменной другой список. Оно сохраняет возможность изменять содержимое `MutableList`.

## Один объект и разные виды доступа

Присваивание списка другой переменной передаёт ссылку на тот же объект. Оно не копирует элементы.

```kotlin
fun main() {
    val editable = mutableListOf("Draft")
    val readable: List<String> = editable
    editable.add("Ready")
    println(readable) // [Draft, Ready]
}
```

Через `readable` нельзя вызвать `add()`, потому что её тип предоставляет только чтение. Но изменение через `editable` видно и через `readable`. Поэтому `List` описывает доступ только для чтения, не гарантируя неизменяемость самого объекта.

В сигнатуре функции `List<String>` сообщает, что функции достаточно читать список. Если задача требует менять переданный список, параметр получает тип `MutableList<String>`. Это различие помогает заметить разрешённые действия уже при чтении сигнатуры.
