Реализуйте функцию `updateQuantity(stock: MutableMap<String, Int>, sku: String, delta: Int): Int`.

Она прибавляет `delta` к текущему количеству товара, записывает новое количество в переданную карту и возвращает его. Для отсутствующего артикула исходное количество равно 0. Остальные записи сохраняются.

```kotlin
fun main() {
    val stock = mutableMapOf("book" to 4)
    updateQuantity(stock, "book", 3) // 7
    updateQuantity(stock, "pen", 2) // 2
    println(stock) // {book=7, pen=2}
}
```

`delta` может быть отрицательным или равным нулю. Все результаты гарантированно неотрицательны и помещаются в `Int`. Даже при нулевом результате запись должна присутствовать в карте. Печатать результат не нужно.
