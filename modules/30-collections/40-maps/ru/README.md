В этом уроке мы изучим карты Kotlin. Разберём поиск по ключу, отсутствие записи и изменение значения. Научимся обновлять данные в переданной карте.

Карта связывает уникальный ключ со значением. Тип `Map<String, Int>` задаёт строковые ключи и целочисленные значения. Ключ помогает получить значение напрямую. Две разные записи могут содержать одинаковые значения, но каждый ключ встречается в карте один раз.

`Map<K, V>` предоставляет чтение. `MutableMap<K, V>` дополнительно разрешает создавать, менять и удалять записи. Буквы `K` и `V` здесь обозначают места для типов ключа и значения.

В каталоге товаров артикул служит ключом, а количество на складе служит значением.

```kotlin
fun main() {
    val stock: Map<String, Int> = mapOf("book" to 4, "pen" to 12)
    println(stock["book"]) // 4
    println(stock["lamp"]) // null
    println(stock.containsKey("pen")) // true
    println(stock.size) // 2
}
```

Запись `"book" to 4` создаёт пару для одной записи. Несколько таких пар передаются в `mapOf()`. Если при создании указать один ключ несколько раз, в карте останется последнее переданное значение для него.

## Отсутствующий ключ

Чтение `stock[key]` возвращает nullable-значение. Даже у `Map<String, Int>` результат имеет тип `Int?`, потому что ключ может отсутствовать. Оператор `?:` помогает явно выбрать значение для такого случая.

```kotlin
fun available(
    stock: Map<String, Int>,
    sku: String,
): Int = stock[sku] ?: 0
```

Ноль в записи и отсутствие записи остаются разными состояниями карты. Если это различие важно, `containsKey()` проверяет именно наличие ключа. В этом уроке значения карты имеют обычный тип `Int`, поэтому `null` при чтении означает отсутствие записи.

## Изменение записей

Для приёмки товаров нужен доступ к изменению карты. `mutableMapOf()` создаёт изменяемую карту, а присваивание по ключу сохраняет значение.

```kotlin
fun main() {
    val stock = mutableMapOf("book" to 4)
    stock["book"] = 7
    stock["lamp"] = 2
    println(stock["book"]) // 7
    println(stock["lamp"]) // 2
    val removed = stock.remove("book")
    println(removed) // 7
    println(stock.containsKey("book")) // false
}
```

Одна запись присваивания обновляет существующий ключ или создаёт новый. Метод `remove()` возвращает удалённое значение, а при отсутствии ключа возвращает `null`.

Если функция получает `MutableMap` как аргумент, её изменения видны вызывающему коду. Возврат нового числа не отменяет того, что сама карта уже обновлена. Через параметр `Map` доступны только операции чтения.
