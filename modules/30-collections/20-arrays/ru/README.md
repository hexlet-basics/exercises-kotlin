В этом уроке мы изучим массивы Kotlin. Разберём фиксированный размер, обход индексов и изменение элементов на месте. Научимся сравнивать содержимое массивов.

Массив хранит упорядоченные элементы и позволяет менять их по индексу. Его размер задаётся при создании и остаётся постоянным. Добавление нового элемента требует другого массива. Для последовательности, которая регулярно растёт, обычно удобнее список.

Тип `Array<String>` описывает массив строк. Для чисел есть специальные виды массивов, например `IntArray`. Он хранит значения `Int` и не совпадает по типу с `Array<Int>`.

В таблице измерений каждому датчику соответствует одна заранее известная позиция. Такой набор можно хранить в массиве.

```kotlin
fun main() {
    val sensors: Array<String> = arrayOf("north", "south")
    val readings: IntArray = intArrayOf(12, 18)
    readings[0] = 15
    println(sensors.size) // 2
    println(readings[0]) // 15
}
```

Функции `arrayOf()` и `intArrayOf()` создают массивы из перечисленных элементов. Синтаксис чтения и записи совпадает с доступом к списку. Индекс за границей вызывает ошибку. У массива из двух элементов допустимы индексы 0 и 1.

## Обход индексов

Свойство `indices` возвращает диапазон всех допустимых индексов. Его удобно использовать, когда программа меняет элементы массива.

Для набора измерений нужно применить одинаковую поправку к каждой позиции.

```kotlin
fun adjust(
    readings: IntArray,
    correction: Int,
) {
    for (index in readings.indices) {
        readings[index] = readings[index] + correction
    }
}

fun main() {
    val readings = intArrayOf(10, 20)
    adjust(readings, 3)
    println(readings[0]) // 13
    println(readings[1]) // 23
}
```

Цикл перебирает числовой диапазон, а массив предоставляет значения по полученным индексам. У пустого массива диапазон `indices` пуст. Тело цикла не выполнится, поэтому отдельная проверка размера здесь не нужна.

Функция получает ссылку на массив. Изменение `readings[index]` видно вызывающему коду после завершения функции. Переменная с `val` продолжает указывать на тот же массив и допускает изменение его элементов.

## Сравнение содержимого

У двух отдельно созданных массивов могут совпадать все элементы. Оператор `==` у массивов не выполняет поэлементное сравнение. Для этой задачи предназначен `contentEquals()`.

```kotlin
fun main() {
    val first = intArrayOf(3, 7)
    val second = intArrayOf(3, 7)
    println(first == second) // false
    println(first.contentEquals(second)) // true
}
```

Проверка содержимого учитывает размер, порядок и значения. Массивы `[3, 7]` и `[7, 3]` имеют разное содержимое. Для вывода всего массива в читаемом виде подходит `contentToString()`.
