Реализуйте функцию `countWords(words: List<String>): Map<String, Int>`. Она возвращает карту, в которой каждому слову соответствует число его появлений в списке.

```kotlin
fun main() {
    countWords(listOf("red", "blue", "red")) // mapOf("red" to 2, "blue" to 1)
    countWords(listOf()) // empty map
}
```

Слова сравниваются с учётом регистра. Пустая строка считается обычным словом. Исходный список менять нельзя, порядок ключей результата не важен.

Создайте отдельную изменяемую карту, обойдите слова в цикле и увеличивайте счётчик по текущему ключу. Печатать результат не нужно.
