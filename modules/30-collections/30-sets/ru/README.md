В этом уроке мы изучим множества Kotlin. Разберём уникальность элементов, проверку принадлежности и изменение набора значений. Научимся получать множество из списка с повторами.

Множество хранит уникальные значения. Повторное добавление равного элемента не увеличивает размер. Здесь важен сам факт присутствия значения, поэтому позиционный доступ по индексу для `Set` не предусмотрен.

Тип `Set<String>` предоставляет чтение множества строк. Тип `MutableSet<String>` дополнительно позволяет добавлять и удалять элементы. Свойство `size` показывает число уникальных элементов.

У документа есть набор меток. Повтор одной метки не должен увеличивать число категорий.

```kotlin
fun main() {
    val labels: Set<String> = setOf("guide", "kotlin", "guide")
    println(labels.size) // 2
    println(labels.contains("guide")) // true
    println("java" in labels) // false
}
```

`contains()` и оператор `in` проверяют принадлежность. Запись `value !in values` проверяет отсутствие значения во множестве. Для строк регистр имеет значение. Метки `"Kotlin"` и `"kotlin"` считаются разными элементами. Пустое множество задаётся, например, как `val labels: Set<String> = setOf()`.

## Получение множества из списка

Функция `toSet()` создаёт множество из элементов списка. Повторяющиеся элементы входят в результат один раз. Исходный список остаётся без изменений.

В список приглашённых могли несколько раз добавить одного человека. Проверка допуска требует только уникальные имена.

```kotlin
fun main() {
    val invited = listOf("Ada", "Linus", "Ada")
    val unique: Set<String> = invited.toSet()
    println(unique.size) // 2
    println("Ada" in unique) // true
    println(invited.size) // 3
}
```

Множества сравниваются через `==` по составу элементов. Порядок создания для такого сравнения не важен. У `Set` как общего типа нет обещания определённого порядка обхода, поэтому правила программы не должны опираться на порядок напечатанных элементов.

## Изменяемое множество

Для редактируемого набора используется `mutableSetOf()`.

```kotlin
fun main() {
    val labels = mutableSetOf("draft")
    println(labels.add("ready")) // true
    println(labels.add("ready")) // false
    println(labels.remove("draft")) // true
    println(labels.remove("missing")) // false
    println(labels.size) // 1
}
```

`add()` возвращает `true`, когда элемент действительно появился. `remove()` возвращает `true`, когда элемент был удалён. Повторное добавление и удаление отсутствующего значения оставляют состав прежним.

Как и со списками, `val` сохраняет ссылку и допускает изменение содержимого `MutableSet`. Через параметр `Set<String>` функция получает доступ только для чтения. Для управления составом переданного набора нужен `MutableSet<String>`.
