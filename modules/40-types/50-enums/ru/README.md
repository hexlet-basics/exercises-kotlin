В этом уроке мы изучим перечисления Kotlin. Разберём объявление фиксированных вариантов и их свойства. Научимся обрабатывать все значения перечисления через `when`.

Когда значение должно быть одним из заранее известных вариантов, строка допускает слишком много лишних состояний. Перечисление задаёт отдельный тип с фиксированным набором констант. Компилятор проверяет, что в параметр такого типа передан один из разрешённых вариантов.

Для уведомлений доступны три уровня важности. Каждый уровень связан с числовым приоритетом.

```kotlin
enum class Priority(
    val rank: Int,
) {
    LOW(1),
    NORMAL(2),
    HIGH(3),
}

fun main() {
    val priority: Priority = Priority.HIGH
    println(priority.rank) // 3
    println(priority == Priority.HIGH) // true
}
```

Каждая константа является отдельным экземпляром `Priority`, созданным при подготовке перечисления. У констант общие объявления свойств и методов, но значения свойств могут различаться. В конструктор `rank` передаются числа, указанные рядом с именами констант.

Имя типа пишется как имя класса, а константы обычно записываются заглавными буквами. Обращение `Priority.HIGH` выбирает конкретный вариант. Передать обычную строку `"HIGH"` вместо значения `Priority` без явного преобразования нельзя.

## Исчерпывающий выбор

Выражение `when` может обработать каждый вариант перечисления. Если перечислены все константы, запасная ветвь `else` не нужна.

Для каждого приоритета сообщение получает короткую подпись.

```kotlin
fun priorityLabel(priority: Priority): String =
    when (priority) {
        Priority.LOW -> "later"
        Priority.NORMAL -> "regular"
        Priority.HIGH -> "urgent"
    }
```

Компилятор знает набор вариантов. Если добавить ещё одну константу, он потребует дополнить этот `when`, потому что выражению нужен результат для каждого допустимого входа. Так изменение набора значений помогает обнаружить места, которые требуют нового решения.

## Все константы

Свойство `entries` предоставляет все константы в порядке их объявления. Их можно обходить обычным циклом.

```kotlin
fun main() {
    for (priority in Priority.entries) {
        println("${priority.name}=${priority.rank}")
    }
}
```

Здесь `name` содержит имя константы, например `"LOW"`. У константы также есть `ordinal`, её позиция начиная с нуля. Позиция меняется при перестановке объявления, поэтому для приоритета или внешнего кода подходит собственное свойство `rank`.

Перечисление удобно, когда все варианты известны заранее и описываются одинаковым набором свойств. Константы не создаются заново при каждом использовании. Отдельные случаи с разными наборами данных потребуют другого способа описания типов.
