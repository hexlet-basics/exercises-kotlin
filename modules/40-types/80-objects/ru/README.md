В этом уроке мы изучим объявления `object` и `companion object`. Разберём обращение к единственному экземпляру и методы создания объектов. Научимся связывать фабричную функцию с именем класса.

Обычный класс позволяет создавать много экземпляров. Иногда программе нужен один объект с общим поведением. Объявление `object` одновременно задаёт его устройство и предоставляет единственный экземпляр. Обращение идёт по имени объявления без вызова конструктора.

В приложении действует общее правило для короткого названия. Правило не хранит изменяемое состояние и может использоваться из разных функций.

```kotlin
object ShortName {
    val missing: String = "unknown"

    fun normalize(text: String): String {
        val cleaned = text.trim()
        return if (cleaned == "") missing else cleaned
    }
}

fun main() {
    println(ShortName.normalize("  Ada ")) // Ada
    println(ShortName.normalize("   ")) // unknown
}
```

`ShortName` обозначает сам объект. Отдельные вызовы его метода используют один экземпляр. Инициализация объявления `object` происходит при первом доступе. Если хранить в нём изменяемые данные, они будут общими для вызывающего кода, поэтому такое состояние требует отдельного внимания.

## Реализация интерфейса

Объект может выполнять знакомый контракт интерфейса. Синтаксис после двоеточия совпадает с реализацией интерфейса классом.

```kotlin
interface NameSource {
    fun name(): String
}

object AnonymousName : NameSource {
    override fun name(): String = "Anonymous"
}

val source: NameSource = AnonymousName
```

Последняя строка сохраняет ссылку на существующий объект. Для него не вызывается `AnonymousName()`.

## Фабрика рядом с классом

Функция создания объекта может иметь отдельное имя и выполнять подготовку аргументов. Такая функция называется фабричной. Если она связана с определённым классом, её можно объявить в `companion object` внутри этого класса.

Участника приложения создают из текста, который сначала нужно нормализовать.

```kotlin
class Participant(
    val name: String,
) {
    companion object {
        fun fromText(text: String): Participant = Participant(ShortName.normalize(text))
    }
}

fun main() {
    val participant = Participant.fromText("  Linus ")
    println(participant.name) // Linus
}
```

Вызов `Participant.fromText()` доступен через имя класса. Для доступа к фабрике заранее создавать участника не нужно. Сам `companion object` существует как один объект, а каждый вызов `fromText()` в этом примере создаёт нового `Participant`.

Обычные методы `Participant` продолжают работать с конкретным экземпляром. Методы его `companion object` служат операциям, связанным с типом, например именованному созданию. Это помогает различать общий способ подготовки объекта и данные каждого созданного участника.
