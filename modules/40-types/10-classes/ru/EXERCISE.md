Создайте класс `Shipment` с первичным конструктором из двух свойств.

- `code` имеет тип `String` и объявляется через `val`.
- `weight` имеет тип `Int` и объявляется через `var`.

Добавьте метод `charge(rate: Int): Int`. Он возвращает произведение текущей массы `weight` на тариф `rate`.

```kotlin
fun main() {
    val shipment = Shipment("P-8", 4)
    shipment.charge(15) // 60
    shipment.weight = 6
    shipment.charge(15) // 90
}
```

Масса и тариф неотрицательны, произведение помещается в `Int`. Каждый экземпляр должен иметь собственную массу. Печатать результат не нужно.
