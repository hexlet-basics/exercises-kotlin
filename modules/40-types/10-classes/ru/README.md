В этом уроке мы изучим классы и экземпляры Kotlin. Разберём первичный конструктор, свойства и методы. Научимся объединять данные с операциями и различать равенство значений и ссылок.

До сих пор программа использовала готовые типы, например `String` и `List`. Класс позволяет описать собственный тип. Он задаёт данные объекта через свойства и действия через методы. Каждый отдельный объект такого класса называется экземпляром и хранит собственные значения свойств.

Объявление класса само по себе не создаёт объект. При создании экземпляра программа вызывает конструктор и передаёт ему начальные данные. Первичный конструктор Kotlin записывается прямо после имени класса.

В приложении доставки у каждой посылки есть код и масса. Стоимость зависит от массы конкретной посылки и тарифа, переданного при расчёте.

```kotlin
class Parcel(
    val code: String,
    var weight: Int,
) {
    fun cost(rate: Int): Int = weight * rate
}

fun main() {
    val parcel = Parcel("BX-4", 3)
    println(parcel.code) // BX-4
    println(parcel.cost(20)) // 60
    parcel.weight = 5
    println(parcel.cost(20)) // 100
}
```

Параметры с `val` и `var` в первичном конструкторе одновременно объявляют свойства. `code` можно читать, а `weight` можно читать и менять. Для создания используется `Parcel(...)` без ключевого слова `new`.

Метод объявляется через `fun` внутри класса. При вызове `parcel.cost(20)` он работает с массой именно этого экземпляра. Другой объект `Parcel` может иметь другой вес и дать другой результат для того же тарифа.

## Ссылка на текущий экземпляр

В методе имя свойства обычно доступно без уточнения. Если параметр метода имеет такое же имя, `this` помогает обратиться к свойству текущего объекта.

```kotlin
class Label(
    var text: String,
) {
    fun rename(text: String) {
        this.text = text
    }
}
```

В правой части присваивания `text` обозначает аргумент метода. Слева `this.text` обозначает свойство объекта. Метод сохраняет новое значение в экземпляре, и оно остаётся доступным после завершения вызова.

## Равенство и один объект

Оператор `===` проверяет, ссылаются ли две переменные на один экземпляр. Оператор `==` использует правило равенства типа. У обычного класса без собственного правила равенства два разных экземпляра считаются разными, даже если их свойства совпадают.

```kotlin
fun main() {
    val first = Parcel("BX-4", 3)
    val second = Parcel("BX-4", 3)
    val same = first
    println(first === same) // true
    println(first === second) // false
    println(first == second) // false
}
```

Присваивание `same = first` сохраняет ссылку на уже существующий объект. Изменение через `same` будет видно и через `first`. Отдельный вызов конструктора создаёт независимый экземпляр. Автоматическое сравнение по полям понадобится классам данных, которые рассматриваются отдельно.
