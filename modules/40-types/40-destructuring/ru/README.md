В этом уроке мы изучим пары и деструктуризацию. Разберём возврат двух результатов и извлечение частей записи. Научимся использовать деструктуризацию при обходе карты.

Иногда одна операция вычисляет два связанных результата. Тип `Pair<A, B>` хранит два значения с типами `A` и `B`. Они могут различаться. Создать пару можно записью `first to second`, а прочитать её части можно через свойства `first` и `second`.

Деструктуризация объявляет несколько локальных переменных из одного значения. Для пары запись `val (left, right) = pair` извлекает её первую и вторую части. Имена переменных выбирает программист, порядок задаёт сам тип.

При переводе длительности в часы и минуты нужны оба результата деления.

```kotlin
fun splitTime(minutes: Int): Pair<Int, Int> = (minutes / 60) to (minutes % 60)

fun main() {
    val result = splitTime(135)
    val (hours, minutes) = result
    println(hours) // 2
    println(minutes) // 15
    println(result.first) // 2
}
```

Функция возвращает одно значение типа `Pair<Int, Int>`. Деструктуризация позволяет удобно дать имена его частям. Для пары подходят два значения, смысл которых понятен в месте использования. Если полей больше или важны их предметные имена, класс данных обычно яснее.

## Класс данных

Компилятор поддерживает деструктуризацию для `data class`. Порядок компонентов совпадает с порядком свойств первичного конструктора.

```kotlin
data class Person(
    val name: String,
    val age: Int,
)

fun main() {
    val (name, age) = Person("Ada", 36)
    println(name) // Ada
    println(age) // 36
}
```

Деструктуризация использует созданные компилятором операции получения компонентов. Их ручное объявление здесь не требуется. Для пропуска ненужного компонента используется `_`, например `val (name, _) = person`. Отдельная переменная для пропущенного значения не создаётся.

## Записи карты

При обходе карты каждая запись предоставляет ключ и значение. При обходе мы сразу получаем отдельные переменные с ключом и значением.

В складском отчёте нужно собрать подписи по артикулам и количествам.

```kotlin
fun stockLabels(stock: Map<String, Int>): List<String> {
    val result = mutableListOf<String>()
    for ((sku, quantity) in stock) {
        result.add("$sku=$quantity")
    }
    return result
}
```

Внешние скобки относятся к заголовку `for`, внутренние выделяют деструктуризацию записи. Вместо `entry.key` и `entry.value` тело получает две переменные.

Если ключ для вычисления не нужен, цикл записывается как `for ((_, quantity) in stock)`. Пустая карта не выполнит ни одной итерации. Деструктуризация меняет способ обращения к частям записи и сохраняет обычные свойства обхода, включая отсутствие обещанного порядка для общего типа `Map`.
