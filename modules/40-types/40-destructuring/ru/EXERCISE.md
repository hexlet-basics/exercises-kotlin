Реализуйте функцию `summarizeStock(stock: Map<String, Int>): Pair<Int, Int>`. Она возвращает пару из двух результатов.

- Первая часть содержит количество артикулов с положительным остатком.
- Вторая часть содержит сумму всех остатков.

```kotlin
fun main() {
    summarizeStock(mapOf("book" to 3, "pen" to 0, "lamp" to 2)) // 2 to 5
    summarizeStock(mapOf()) // 0 to 0
}
```

Все количества неотрицательны, сумма помещается в `Int`. При обходе карты используйте деструктуризацию и пропустите ненужный ключ через `_`. Исходную карту менять нельзя. Печатать результат не нужно.
