В готовом окружении есть базовый класс `Parcel`. Он хранит массу в свойстве `protected val weight: Int` и предоставляет открытый метод `price(): Int`, который возвращает `weight * 10`. Метод `label(): String` возвращает строку `"Price: ${price()}"`.

Создайте производный класс `ExpressParcel(weight: Int)`. Передайте массу конструктору родителя и переопределите `price()`. Цена срочной доставки равна базовой цене плюс `weight * 2`. Используйте `super.price()` и унаследованное свойство `weight`.

```kotlin
fun main() {
    val parcel: Parcel = ExpressParcel(5)
    parcel.price() // 60
    parcel.label() // Price: 60
}
```

Масса находится от 0 до 1000 включительно. Базовый класс менять не нужно. Печатать результат не нужно.
