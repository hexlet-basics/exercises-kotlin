В этом уроке мы изучим свойства и управление состоянием объекта. Разберём вычисляемые свойства, ограничения записи и блок инициализации. Научимся менять данные через методы и сохранять правила объекта.

Если свойство открыто для записи, вызывающий код может присвоить ему любое значение допустимого типа. Иногда объект должен управлять такими изменениями сам. Например, счётчик может разрешать только увеличение или сброс. Ограничение записи позволяет оставить чтение доступным и сосредоточить изменения в методах класса.

У свойства есть операция чтения, которая называется getter. У изменяемого свойства есть также операция записи, setter. Kotlin создаёт их автоматически, а при необходимости позволяет уточнить их доступность или вычисление.

Счётчик просмотров хранит число событий. Его значение можно прочитать снаружи, а увеличить можно только вызовом метода.

```kotlin
class ViewCounter(
    start: Int,
) {
    var value: Int = start
        private set

    fun record() {
        value = value + 1
    }
}
```

`private set` сохраняет публичное чтение `value` и разрешает запись только внутри `ViewCounter`. Вызов `counter.record()` меняет значение. Присваивание `counter.value = 50` из другого кода компилятор отклонит.

Слово `private` перед свойством или методом закрывает весь этот член класса от внешнего кода. Это полезно для промежуточных данных и вспомогательных действий, которыми управляет только сам объект.

## Вычисляемое свойство

Свойству не обязательно хранить отдельное значение. Getter может вычислять результат при каждом обращении.

```kotlin
class Rectangle(
    val width: Int,
    val height: Int,
) {
    val area: Int
        get() = width * height
}

fun main() {
    val rectangle = Rectangle(3, 4)
    println(rectangle.area) // 12
}
```

`area` зависит от других свойств. Объявление `get()` показывает, что при чтении программа вычисляет произведение. Скобки при обращении `rectangle.area` не нужны. Вычисляемое свойство помогает не хранить второй результат, который пришлось бы согласовывать с исходными данными.

## Начальное состояние

Параметр конструктора без `val` или `var` сам не становится свойством. Его можно использовать для подготовки начального состояния. Если при создании нужно выполнить несколько действий или условие, они помещаются в блок `init`.

Переданное начало счётчика может быть отрицательным. При создании объект заменяет его нулём.

```kotlin
class SafeCounter(
    start: Int,
) {
    var value: Int = start
        private set

    init {
        if (value < 0) {
            value = 0
        }
    }
}
```

Блок выполняется при создании каждого экземпляра после расположенных перед ним инициализаторов свойств. `init` не является методом для повторного вызова. Он подготавливает состояние, с которым объект затем будет работать. Правила последующих изменений реализуются в методах.
