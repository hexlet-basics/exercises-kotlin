В этом уроке мы изучим безопасные вызовы и оператор Элвиса. Разберём цепочки обращений к необязательному значению. Научимся выбирать запасной результат и завершать функцию при отсутствии данных.

Когда переменная может содержать `null`, перед обращением к её свойству приходится проверять значение. Безопасный вызов `?.` объединяет проверку и обращение. При наличии объекта он выполняет указанную операцию. При `null` он пропускает операцию и возвращает `null`.

В каталоге иногда отсутствует краткое название товара. Для присутствующего названия приложение вычисляет длину.

```kotlin
fun titleLength(title: String?): Int? = title?.length

fun main() {
    println(titleLength("Book")) // 4
    println(titleLength(null)) // null
}
```

У `String.length` тип `Int`, но у выражения `title?.length` тип `Int?`. Возможность отсутствия сохраняется в результате безопасного вызова.

## Запасное значение

Оператор Элвиса `?:` возвращает левое значение, если оно отличается от `null`. Если слева `null`, он вычисляет правую часть. Ноль, `false` и пустая строка не вызывают переход вправо.

При подготовке подписи отсутствующее название получает слово `Untitled`. Если название передали, программа удаляет внешние пробелы и переводит его в нижний регистр.

```kotlin
fun displayTitle(title: String?): String = title?.trim()?.lowercase() ?: "Untitled"

fun main() {
    println(displayTitle("  GUIDE ")) // guide
    println(displayTitle(null)) // Untitled
    println(displayTitle("")) // Пустая строка
}
```

Каждый `?.` продолжает цепочку только при наличии значения слева. При исходном `null` вызовы `trim()` и `lowercase()` не происходят. Пустая строка проходит всю цепочку и остаётся пустой, поэтому `?:` не подставляет для неё подпись.

## Ранний выход

Правой частью `?:` может быть `return`. Это позволяет остановить обработку, когда обязательных для неё данных нет.

```kotlin
fun normalizedCode(code: String?): String {
    val presentCode = code ?: return "missing"
    return presentCode.trim().lowercase()
}
```

После присваивания `presentCode` имеет тип `String`. При `null` функция уже завершилась, поэтому дальнейшее обращение к методам строки допустимо.

Оператор `!!` тоже позволяет обратиться к nullable-значению как к обязательному, но при `null` он завершает выполнение с ошибкой `NullPointerException`. Проверка компилятора при этом заменяется обещанием программиста. Для ожидаемого отсутствия подходят безопасный вызов, проверка или запасное значение, которые явно задают результат программы.
