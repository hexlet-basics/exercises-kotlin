Реализуйте функцию `visibleLength(text: String?, fallback: Int): Int`. Для присутствующей строки она удаляет пробелы по краям и возвращает длину оставшегося текста. При `null` функция возвращает `fallback` без изменения.

Пустая строка и строка из пробелов имеют длину 0. Значение по умолчанию применяется только при `null`. Для вычисления длины используйте безопасный вызов и `?:`.

```kotlin
fun main() {
    visibleLength("  Kotlin ", 10) // 6
    visibleLength(null, 10) // 10
    visibleLength("   ", 10) // 0
    visibleLength("", 5) // 0
}
```

В строках упражнения используются символы ASCII. Печатать результат не нужно.
