Реализуйте функцию `readCount(value: Any?): Int?`.

Она обрабатывает вход по его типу.

- Значение `Int` возвращается без изменения.
- У строки удаляются пробелы по краям, затем она преобразуется через `toIntOrNull()`.
- Для всех остальных значений возвращается `null`, в том числе для `Long`, `Double`, `Boolean` и самого `null`.

```kotlin
fun main() {
    readCount(12) // 12
    readCount(" 34 ") // 34
    readCount("many") // null
    readCount(12L) // null
    readCount(null) // null
}
```

Используйте проверки `is`. Ограничений на знак целого числа нет. Печатать результат не нужно.
