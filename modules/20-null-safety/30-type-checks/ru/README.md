В этом уроке мы изучим проверку и приведение типов. Разберём работу с общим типом `Any` и уточнение типа после условия. Научимся безопасно получать значение нужного типа из неоднородного входа.

Параметр с типом `Any` принимает любое значение, кроме `null`. Через такую переменную доступно только поведение, общее для всех объектов. Например, компилятор не разрешает обращаться к `length`, пока не известно, что внутри находится строка. Тип `Any?` допускает ещё и `null`.

Общий тип полезен на границе с данными неизвестной формы. Внутри обработки программа проверяет конкретный тип и выбирает соответствующее действие. Проверка `value is String` возвращает логическое значение. Противоположная проверка записывается как `value !is String`.

В сообщении из внешнего источника может оказаться строка или число. Функция ниже вычисляет длину только для строк.

```kotlin
fun messageLength(value: Any?): Int? {
    if (value is String) {
        return value.length
    }
    return null
}

fun main() {
    println(messageLength("Ready")) // 5
    println(messageLength(123)) // null
    println(messageLength(null)) // null
}
```

В ветви `is String` срабатывает smart cast. Компилятор разрешает методы и свойства строки, потому что условие уже подтвердило её тип. Проверка типа также исключает `null`.

## Уточнение после раннего возврата

Если отрицательная проверка завершает функцию, оставшаяся часть может работать с уточнённым типом.

```kotlin
fun cleanedLength(value: Any?): Int? {
    if (value !is String) {
        return null
    }
    return value.trim().length
}
```

Проверка относится к типу самого значения. Число `123` не становится строкой из-за того, что его можно напечатать. Преобразование значения в другой вид и проверка уже существующего типа решают разные задачи.

## Безопасное приведение

Оператор `as?` пытается представить значение как указанный тип. При несовпадении типов он возвращает `null`.

```kotlin
fun normalizedMessage(value: Any?): String? {
    val text = value as? String
    return text?.trim()?.lowercase()
}
```

Здесь `text` получает тип `String?`. Значения `null` и `42` дадут `null`, а строка `"  DONE "` превратится в `"done"`.

Принудительный оператор `as` при несовместимом типе завершает выполнение с `ClassCastException`. Он подходит только там, где программист уже обеспечил нужный тип другим способом. Для обычной обработки неоднородного входа проверка `is` или приведение `as?` позволяют явно задать поведение при несовпадении.
