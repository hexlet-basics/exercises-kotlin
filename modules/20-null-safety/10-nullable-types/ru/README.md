В этом уроке мы изучим nullable-типы Kotlin. Разберём объявления, проверки на отсутствие значения и преобразование текста в число. Научимся возвращать результат, который может отсутствовать.

Функция не всегда может вычислить ответ для переданного аргумента. Для такой ситуации Kotlin позволяет включить отсутствие значения в тип результата. Тип `Int` допускает целые числа, а `Int?` дополнительно допускает `null`. Знак `?` после имени типа делает его nullable-типом.

Пустая строка, ноль и `null` имеют разный смысл. Пустая строка остаётся строкой, ноль остаётся числом. Значение `null` сообщает, что самого результата нет. Компилятор требует учитывать эту возможность перед операцией над результатом.

## Объявление и проверка

В настройках приложения номер комнаты может отсутствовать. Когда номер известен, переменная хранит число. Когда его ещё не выбрали, она хранит `null`.

```kotlin
fun main() {
    var room: Int? = null
    room = 12

    val title: String? = "Kotlin"
    if (title != null) {
        println(title.length) // 6
    }
}
```

После проверки `title != null` компилятор знает, что внутри ветви находится строка. Он разрешает обращение к `length` без дополнительного преобразования. Такое уточнение называется smart cast. Здесь `title` объявлена через `val`, поэтому между проверкой и использованием её значение не поменяется.

У обычного `String` свойство `length` доступно сразу. Для `String?` прямое обращение без проверки компилятор отклонит. Так необязательное значение нельзя случайно использовать как обязательное.

## Отсутствующий результат функции

Стандартная функция `toIntOrNull()` пытается прочитать целое число из строки. При успехе она возвращает `Int`, при неудаче возвращает `null`. Тип всего результата записывается как `Int?`.

В форме настроек пользователь вводит число попыток. Обработчик разрешает значения от 1 до 5 и сообщает об отсутствии допустимого числа через `null`.

```kotlin
fun parseAttempts(text: String): Int? {
    val number = text.toIntOrNull()
    if (number == null) {
        return null
    }
    if (number < 1 || number > 5) {
        return null
    }
    return number
}

fun main() {
    println(parseAttempts("3")) // 3
    println(parseAttempts("many")) // null
    println(parseAttempts("9")) // null
}
```

После раннего `return` для `null` компилятор рассматривает `number` как `Int` в оставшейся части функции. Условие диапазона уже работает с обычным числом.

`toIntOrNull()` принимает знак числа, но не удаляет пробелы. Для ввода с внешними пробелами сначала вызывают `trim()`. Если число не помещается в `Int`, результатом также будет `null`. Отдельная проверка диапазона отвечает за правила приложения, которые преобразование строки само не знает.
