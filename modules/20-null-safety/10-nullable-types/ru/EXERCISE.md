Реализуйте функцию `parsePercent(text: String): Int?`. Она получает текстовое значение процента и возвращает число от 0 до 100 включительно.

Сначала удалите пробелы по краям строки. Если оставшийся текст нельзя преобразовать в `Int` или число выходит за допустимый диапазон, верните `null`. Пустая строка тоже даёт `null`.

```kotlin
fun main() {
    parsePercent(" 75 ") // 75
    parsePercent("0") // 0
    parsePercent("100") // 100
    parsePercent("101") // null
    parsePercent("75%") // null
}
```

Используйте `toIntOrNull()` и явную проверку на `null`. Печатать результат не нужно.
