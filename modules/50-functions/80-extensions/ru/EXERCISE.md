Объявите расширение `String.normalizedCode(): String`. Оно должно убрать пробелы по краям строки и привести оставшийся текст к нижнему регистру через `lowercase`.

Внутренние пробелы и прочие символы сохраняются. Строка из одних пробелов превращается в пустую строку. Исходное строковое значение остаётся прежним.

```kotlin
fun main() {
    println("  ITEM 42  ".normalizedCode()) // item 42
}
```
