В этом уроке мы изучим объявление функций расширения. Разберём тип получателя, доступ через `this` и правила выбора вызываемой функции. Научимся добавлять удобную форму вызова к существующему типу.

Функция может выполнять действие над значением, которое передаётся первым аргументом. Если это действие относится к одному типу, Kotlin позволяет записать его в форме расширения. При вызове значение появляется слева от точки и называется получателем.

Предположим, мы формируем подписи для папок. К готовому имени требуется добавлять отметку архива. Такое действие удобно записать как операцию над строкой.

```kotlin
fun String.archived(): String = "$this [archive]"

fun main() {
    println("reports".archived()) // reports [archive]
}
```

Перед именем `archived` стоит тип получателя `String`. Внутри функции `this` обозначает строку, для которой сделали вызов. Возвращаемый тип остаётся справа от списка параметров. Функция объявлена на уровне файла и не требует доступа к исходному коду класса `String`.

Расширение не добавляет новое поле или метод внутрь класса. Компилятор разрешает удобную форму вызова отдельной функции. Поэтому расширение видит те свойства и методы, которые доступны обычному коду в месте его объявления. Закрытые свойства чужого класса ему недоступны. Для использования расширения из другого пакета требуется обычный `import`.

## Как выбирается расширение

Выбор зависит от типа получателя, известного компилятору в месте вызова. Фактический класс объекта не меняет выбранную функцию расширения.

Пусть для документа и его уточнённого вида объявлены разные подписи. Через переменную базового типа будет выбрана подпись базового типа.

```kotlin
open class Document

class Report : Document()

fun Document.kind(): String = "document"

fun Report.kind(): String = "report"

fun main() {
    val report = Report()
    val document: Document = report
    println(report.kind()) // report
    println(document.kind()) // document
}
```

В обоих вызовах объект один и тот же. Однако тип переменной `document` равен `Document`, поэтому компилятор выбирает соответствующее расширение. Это отличается от вызова переопределённого метода, который выбирается по фактическому классу объекта.

Если у класса уже есть доступный метод с подходящим именем и параметрами, приоритет получает этот метод. Расширение с такой же сигнатурой его не заменяет. Чтобы название операции не вводило читателя в заблуждение, новое расширение должно дополнять доступный интерфейс типа и иметь самостоятельное назначение.
