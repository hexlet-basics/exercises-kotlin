В этом уроке мы изучим настройку объекта через `apply`. Разберём лямбду с получателем и возвращаемое значение вызова. Научимся собирать настроенный экземпляр и выбирать между `apply` и `let`.

Когда после создания экземпляра нужно установить несколько свойств, каждое присваивание обращается к одному объекту. Функция `apply` объединяет эти действия в блок настройки. Внутри блока объект доступен как получатель `this`, а результат всего вызова совпадает с исходным объектом.

Предположим, приложение создаёт параметры печати. После создания нужно задать число копий и включить двусторонний режим.

```kotlin
class PrintOptions {
    var copies: Int = 1
    var duplex: Boolean = false
}

fun main() {
    val options =
        PrintOptions().apply {
            copies = 3
            duplex = true
        }
    println(options.copies) // 3
    println(options.duplex) // true
}
```

В блоке можно написать `this.copies = 3`. В данном случае `this` разрешается опустить, поскольку имя свойства однозначно. Фигурные скобки здесь содержат лямбду с получателем. Она отличается от уже знакомой лямбды с аргументом `it`, потому что свойства получателя доступны напрямую.

## Результат настройки

Последнее выражение блока `apply` не определяет его результат. Даже если блок заканчивается числом или строкой, вызов возвращает настроенный экземпляр.

```kotlin
class PrintOptions {
    var copies: Int = 1
}

fun main() {
    val original = PrintOptions()
    val result =
        original.apply {
            copies = 4
        }
    println(result === original) // true
    println(original.copies) // 4
}
```

`apply` работает с исходным экземпляром и не создаёт его копию. Создание произошло отдельно при вызове `PrintOptions()`. Если тот же объект доступен через другую ссылку, изменение свойств будет видно и через неё.

При совпадении имени параметра и свойства получателя используем `this`, чтобы обозначить свойство явно.

```kotlin
class PrintOptions {
    var copies: Int = 1
}

fun createOptions(copies: Int): PrintOptions =
    PrintOptions().apply {
        this.copies = copies
    }
```

Слева от присваивания находится свойство создаваемого экземпляра. Справа находится аргумент `createOptions`. Без уточнения `this` одинаковые имена затрудняют чтение, а попытка присвоить значение параметру приведёт к ошибке.

Для преобразования в новое значение подходит `let`, у которого результат задаёт лямбда. Для настройки с возвратом того же объекта подходит `apply`. В обоих случаях блок должен оставаться небольшим. Несколько вложенных получателей с одинаковыми именами свойств усложняют определение того, к какому объекту относится присваивание.
