Реализуйте функцию `discountedPrice(price: Int): Int`. Она принимает целую цену от `0` до `100000` и возвращает цену после скидки в 10 процентов. Дробная часть результата отбрасывается.

Внутри функции сохраните расчёт скидки в локальной переменной с типом `(Int) -> Int`, затем вызовите полученную функцию с аргументом `price`.

```kotlin
fun main() {
    val result = discountedPrice(125)
    println(result) // 112
}
```
