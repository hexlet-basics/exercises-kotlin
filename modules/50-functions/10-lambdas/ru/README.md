В этом уроке мы изучим функции как значения и запись лямбд в Kotlin. Разберём объявление типа функции и получение результата из блока. Научимся сохранять операцию в переменной и вызывать её с аргументом.

Когда одну операцию нужно сохранить для дальнейшего вызова, ей можно дать имя переменной. Значением этой переменной будет функция. Тип функции описывает типы входных аргументов и результата. Запись `(Int) -> Int` означает, что функция принимает одно целое число и возвращает целое число.

Представим, что мы рассчитываем упаковку заказа. Каждую коробку нужно учитывать с запасом в два сантиметра. Сохраним этот расчёт в переменной и применим к нескольким размерам.

```kotlin
fun main() {
    val withMargin: (Int) -> Int = { size -> size + 2 }
    println(withMargin(10)) // 12
    println(withMargin(24)) // 26
}
```

В фигурных скобках записана лямбда, то есть функция без отдельного объявления через `fun`. Имя параметра находится перед `->`, а тело после него. При вызове `withMargin(10)` число `10` становится значением `size`. Круглые скобки вызывают функцию, сохранённую в переменной.

## Типы и результат

Компилятор узнаёт тип `size` из аннотации переменной. Если у переменной нет аннотации, тип параметра можно записать внутри лямбды. Результатом служит последнее выражение тела. Обычный `return` для этого не нужен.

Допустим, стоимость хранения зависит от объёма. Внутри лямбды сначала вычислим промежуточную цену, а затем прибавим обязательную плату.

```kotlin
fun main() {
    val storagePrice = { volume: Int ->
        val variablePart = volume * 3
        variablePart + 5
    }
    println(storagePrice(4)) // 17
}
```

Тип `storagePrice` компилятор выводит как `(Int) -> Int`. Промежуточное объявление `variablePart` не определяет результат блока. Результат задаёт выражение `variablePart + 5`.

Если лямбда принимает единственный параметр и компилятор уже знает его тип, вместо объявления параметра можно использовать имя `it`.

```kotlin
fun main() {
    val triple: (Int) -> Int = { it * 3 }
    println(triple(7)) // 21
}
```

У лямбды без аргументов тип начинается с `()`, например `() -> String`. Для нескольких аргументов их типы перечисляются через запятую, например `(Int, Int) -> Int`. Стрелка в типе всегда отделяет результат от входов.
