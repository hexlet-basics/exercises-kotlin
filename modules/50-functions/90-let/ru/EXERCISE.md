Реализуйте `labelLength(text: String?): Int?`. При наличии строки функция должна убрать пробелы по краям и вернуть длину очищенного текста. Для `null` верните `null`. Строка из одних пробелов даёт `0`.

Используйте безопасный вызов вместе с `let`. Вход содержит только ASCII-символы, поэтому длина соответствует числу символов.

```kotlin
fun main() {
    println(labelLength("  a b  ")) // 3
    println(labelLength(null)) // null
}
```
