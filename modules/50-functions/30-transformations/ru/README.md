В этом уроке мы изучим отбор и преобразование элементов коллекций. Разберём функции `filter`, `map` и `mapNotNull` и порядок их вызовов. Научимся получать новый список, сохраняя исходные данные.

При обработке списка часто нужно отделить подходящие элементы и получить из них другие значения. В Kotlin эти действия выражаются функциями стандартной библиотеки. Каждая принимает лямбду, которая описывает обработку одного элемента.

Предположим, мы составляем список доступных мест. Числа обозначают вместимость комнат, а в результат должны попасть комнаты хотя бы на четыре человека.

```kotlin
fun main() {
    val capacities = listOf(2, 6, 4, 1)
    val suitable = capacities.filter { it >= 4 }
    val labels = suitable.map { "Room for $it" }
    println(suitable) // [6, 4]
    println(labels) // [Room for 6, Room for 4]
    println(capacities) // [2, 6, 4, 1]
}
```

Лямбда `filter` возвращает `Boolean`. Значение `true` оставляет элемент, а `false` пропускает его. Лямбда `map` возвращает новое значение для каждого элемента, поэтому здесь `List<Int>` превращается в `List<String>`. Операции сохраняют относительный порядок выбранных элементов и не меняют исходный список.

## Преобразование с возможным отсутствием результата

Обычный `map` сохраняет результат для каждого входа, включая `null`. Функция `mapNotNull` оставляет только результаты, отличные от `null`. Это удобно, если преобразование может оказаться неприменимым к отдельной записи. Пустая строка остаётся в результате, потому что она представляет значение типа `String`.

Пусть настройки приходят строками. Некоторые из них содержат целые числа, а остальные описывают другие данные.

```kotlin
fun main() {
    val settings = listOf("12", "auto", "5", "")
    val nullableValues = settings.map { it.toIntOrNull() }
    val numbers = settings.mapNotNull { it.toIntOrNull() }
    println(nullableValues) // [12, null, 5, null]
    println(numbers) // [12, 5]
}
```

Тип `nullableValues` равен `List<Int?>`, а тип `numbers` равен `List<Int>`. Удаление `null` относится к результату лямбды. Входная строка сама по себе не обязана быть nullable.

## Порядок действий

Вызовы можно соединить в цепочку. Каждый следующий вызов работает с результатом предыдущего. Поэтому тип `it` может меняться между соседними лямбдами.

```kotlin
fun main() {
    val values = listOf(" 3 ", "12", "bad", " 8")
    val result =
        values
            .map { it.trim() }
            .mapNotNull { it.toIntOrNull() }
            .filter { it >= 8 }
    println(result) // [12, 8]
}
```

Первая операция принимает строку и возвращает строку. Вторая получает очищенный текст и возвращает число либо `null`. В последней лямбде `it` уже имеет тип `Int`. Эти операции над списками выполняются сразу и создают промежуточные списки. Перестановка шагов может изменить результат или сделать выражение несовместимым по типам.
