В этом уроке мы изучим поиск и проверку элементов коллекции по условию. Разберём функции `find`, `any` и `all` на непустом и пустом списке. Научимся выбирать между найденным значением и ответом на логический вопрос.

Если нужен один подходящий элемент, полный список после `filter` избыточен. Функция `find` обходит элементы в порядке коллекции и возвращает первый, для которого лямбда дала `true`. Такую лямбду с логическим результатом называют предикатом. Если подходящего элемента нет, `find` возвращает `null`.

Представим, что в списке находятся длительности свободных интервалов. Для встречи нужен первый интервал хотя бы на полчаса.

```kotlin
fun main() {
    val durations = listOf(10, 40, 30, 60)
    val firstSuitable = durations.find { it >= 30 }
    println(firstSuitable) // 40
    println(durations.find { it >= 90 }) // null
}
```

Результат первого поиска имеет тип `Int?`. Значение `40` выбирается из-за положения в списке. Функция не ищет минимум среди подходящих значений. После первого совпадения она прекращает поиск.

## Проверка существования и общего условия

Если значение элемента не нужно, вопрос удобно сформулировать через `any` или `all`. Функция `any` проверяет существование хотя бы одного совпадения. Функция `all` требует выполнения условия для каждого элемента.

Допустим, перед сохранением измерений нужно проверить, встречалось ли превышение нормы и допустимы ли все значения.

```kotlin
fun main() {
    val readings = listOf(2, 8, 5)
    println(readings.any { it > 7 }) // true
    println(readings.all { it >= 0 }) // true
    println(readings.all { it < 7 }) // false
}
```

`any` может закончить работу после первого `true`, а `all` после первого `false`. Предикат описывает только проверку. Изменение внешнего состояния внутри него затрудняет понимание того, сколько элементов действительно были просмотрены.

## Пустая коллекция

Поведение пустого входа зависит от вопроса. Подходящего элемента в пустом списке нет, поэтому `find` возвращает `null`, а `any` возвращает `false`. Нарушения общего условия тоже нет, поэтому `all` возвращает `true`.

```kotlin
fun main() {
    val empty = listOf<Int>()
    println(empty.find { it > 0 }) // null
    println(empty.any { it > 0 }) // false
    println(empty.all { it > 0 }) // true
}
```

Если по правилам задачи список должен содержать хотя бы один элемент, это требование нужно выразить отдельно. Например, `values.any() && values.all { it > 0 }` проверяет и наличие элементов, и общее условие. Вызов `any()` без лямбды проверяет непустоту.
