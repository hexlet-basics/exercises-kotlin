В этом уроке мы изучим передачу и возврат функций в Kotlin. Разберём завершающую лямбду, ссылки на функции и захват окружения. Научимся создавать операции с сохранёнными параметрами и управлять возвратом из лямбды.

Функция высшего порядка принимает другую функцию или возвращает её. Тип операции записывается обычным типом параметра. Благодаря этому вызывающий код выбирает действие, а функция управляет тем, когда его выполнить.

Предположим, модуль обработки чисел должен применять выбранное преобразование два раза. Само преобразование передадим аргументом.

```kotlin
fun twice(
    value: Int,
    operation: (Int) -> Int,
): Int = operation(operation(value))

fun addThree(value: Int): Int = value + 3

fun main() {
    println(twice(4, ::addThree)) // 10
    println(twice(4) { it * 2 }) // 16
}
```

Запись `::addThree` получает ссылку на объявленную функцию без её вызова. Во втором вызове мы сразу создаём лямбду. Когда функция принимает лямбду последним аргументом, её можно вынести за круглые скобки. Здесь сначала получаем `8`, затем передаём это число той же операции и получаем `16`.

## Сохранённое окружение

Возвращаемая лямбда может обращаться к параметрам и локальным переменным той функции, в которой её создали. Такое сочетание функции и сохранённого окружения называют замыканием.

Представим, что каждому устройству нужен свой сдвиг измерения. Фабрика создаёт операцию с выбранной поправкой.

```kotlin
fun makeOffset(offset: Int): (Int) -> Int = { value -> value + offset }

fun main() {
    val indoor = makeOffset(2)
    val outdoor = makeOffset(-1)
    println(indoor(10)) // 12
    println(outdoor(10)) // 9
    println(indoor(20)) // 22
}
```

Оба вызова `makeOffset` уже завершились, но их лямбды сохранили доступ к своим значениям `offset`. Создание `outdoor` не меняет поправку `indoor`. Если захвачена переменная `var`, лямбда читает и изменяет её значение, а несколько лямбд из одного окружения могут разделять эту переменную.

## Локальный возврат

Результат лямбды обычно задаёт последнее выражение. Для досрочного выхода можно назначить лямбде метку и написать `return@метка`.

```kotlin
fun applyOnce(
    value: Int,
    operation: (Int) -> Int,
): Int = operation(value)

fun main() {
    val result =
        applyOnce(-4) operation@{ value ->
            if (value < 0) return@operation 0
            value * 2
        }
    println(result) // 0
}
```

`return@operation` завершает только помеченную лямбду. Управление возвращается в `applyOnce`, затем вызов `println` выполняется как обычно. Обычный `return` внутри лямбд зависит от дополнительных правил, поэтому здесь используем явно обозначенный локальный выход.
