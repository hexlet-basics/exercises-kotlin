Реализуйте `makeMultiplier(factor: Int): (Int) -> Int`. Функция должна создавать и возвращать операцию, которая умножает свой аргумент на сохранённое значение `factor`.

Созданные операции должны работать независимо. Повторный вызов фабрики с другим множителем не меняет ранее созданные функции. Множитель и аргументы находятся в диапазоне от `-1000` до `1000`.

```kotlin
fun main() {
    val timesFour = makeMultiplier(4)
    println(timesFour(3)) // 12
    println(timesFour(-2)) // -8
}
```
