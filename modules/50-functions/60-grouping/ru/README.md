В этом уроке мы изучим построение карт из коллекций. Разберём группировку через `groupBy` и создание индекса через `associateBy`. Научимся выбирать результат для ключей, которые встречаются несколько раз.

Карта позволяет обращаться к данным по ключу. Когда исходные данные представлены списком записей, ключ можно вычислить из каждой записи. Функция `groupBy` собирает под одним ключом все подходящие элементы, а `associateBy` сохраняет для ключа один элемент.

Представим, что мы распределяем посылки по пунктам выдачи. В списке каждая посылка хранит номер и название пункта. Для каждого пункта нужно получить отдельный список.

```kotlin
data class Parcel(
    val id: Int,
    val station: String,
)

fun main() {
    val parcels =
        listOf(
            Parcel(10, "North"),
            Parcel(11, "South"),
            Parcel(12, "North"),
        )
    val byStation = parcels.groupBy { it.station }
    println(byStation["North"]) // [Parcel(id=10, station=North), Parcel(id=12, station=North)]
    println(byStation["West"]) // null
}
```

Тип результата равен `Map<String, List<Parcel>>`. Лямбда выбирает только ключ, а в список группы попадают сами посылки. Внутри каждой группы элементы сохраняют порядок исходного списка. Для отсутствующей группы карта возвращает `null` по обычным правилам доступа.

## Индекс по одному элементу

Теперь предположим, что нам требуется искать посылку по номеру. Функция `associateBy` создаёт карту, где ключу соответствует одна запись.

```kotlin
data class Parcel(
    val id: Int,
    val station: String,
)

fun main() {
    val parcels = listOf(Parcel(10, "North"), Parcel(11, "South"))
    val byId = parcels.associateBy { it.id }
    println(byId[11]) // Parcel(id=11, station=South)
}
```

Тип `byId` равен `Map<Int, Parcel>`. Если несколько элементов получили одинаковый ключ, в результате остаётся последний из них. Это правило нужно учитывать до выбора операции.

Пусть список содержит несколько обновлений одной посылки. Индекс будет хранить последнее известное назначение, а группировка позволит сохранить историю.

```kotlin
data class Parcel(
    val id: Int,
    val station: String,
)

fun main() {
    val updates = listOf(Parcel(10, "North"), Parcel(10, "South"))
    println(updates.associateBy { it.id }[10]) // Parcel(id=10, station=South)
    println(updates.groupBy { it.id }[10]?.size) // 2
}
```

Обе операции возвращают новую карту и не переставляют исходный список. Элементы внутри результатов остаются теми же объектами. Создание карты само по себе не выполняет глубокого копирования записей. Для пустого списка результатом обеих операций служит пустая карта.
