В этом уроке мы изучим накопление результата при обработке коллекции. Разберём готовые агрегатные функции и последовательное вычисление через `fold`. Научимся выбирать начальное значение и определять результат для пустого входа.

Иногда результат обработки списка состоит из одного значения. Сумма платежей, наибольшее измерение или остаток после последовательных операций зависят от всех входных элементов. Такие вычисления называют агрегированием.

Для распространённых операций в стандартной библиотеке есть готовые функции. Предположим, список хранит число страниц в нескольких документах. Найдём максимальный размер документа и оценим общий объём печати по два экземпляра.

```kotlin
fun main() {
    val pages = listOf(3, 8, 5)
    println(pages.maxOrNull()) // 8
    println(pages.sumOf { it * 2 }) // 32
    println(listOf<Int>().maxOrNull()) // null
    println(listOf<Int>().sumOf { it * 2 }) // 0
}
```

`sumOf` сначала получает число из каждого элемента через лямбду, затем суммирует результаты. Тип результата зависит от числового типа, который возвращает лямбда. У пустой суммы результат равен нулю. Максимального элемента в пустом списке нет, поэтому `maxOrNull` возвращает nullable-тип.

## Аккумулятор и fold

Когда готовой операции недостаточно, `fold` позволяет задать правило следующего шага. Он принимает начальный результат и лямбду с двумя аргументами. Первый аргумент содержит накопленный результат, второй содержит очередной элемент. Результат лямбды становится аккумулятором для следующего шага.

Представим, что мы строим строковое обозначение пути. Начальное имя каталога уже известно, а список содержит следующие части.

```kotlin
fun main() {
    val parts = listOf("drafts", "today")
    val path =
        parts.fold("home") { accumulated, part ->
            "$accumulated/$part"
        }
    println(path) // home/drafts/today
}
```

Первый шаг получает `"home"` и `"drafts"`, затем возвращает `"home/drafts"`. Второй шаг получает эту строку и `"today"`. Тип аккумулятора здесь `String`. Тип элемента тоже `String`, но совпадение типов не обязательно. Например, список строк можно свернуть в число их общих символов.

Начальное значение входит в результат ровно один раз. Если элементов нет, лямбда не вызывается, а `fold` возвращает начальное значение без изменений.

```kotlin
fun main() {
    val lengths =
        listOf("ab", "cde").fold(0) { total, word ->
            total + word.length
        }
    val emptyPath = listOf<String>().fold("home") { path, part -> "$path/$part" }
    println(lengths) // 5
    println(emptyPath) // home
}
```

Правило накопления применяется слева направо. Для вычитания, сборки текста и других зависимых от порядка действий перестановка элементов может изменить результат.
