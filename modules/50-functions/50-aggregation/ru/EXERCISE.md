Реализуйте `balanceAfter(start: Int, changes: List<Int>): Int`. Аргумент `start` содержит начальное число баллов. Каждый элемент `changes` изменяет текущий баланс, положительное число прибавляет баллы, отрицательное списывает их.

После каждого изменения баланс не может оказаться ниже нуля. Если очередное изменение даёт отрицательный результат, следующий шаг начинается с нуля. Используйте `fold`. Для пустого списка верните `start`. Начальный баланс находится в диапазоне от `0` до `10000`, изменений не больше `100`, каждое находится в диапазоне от `-1000` до `1000`.

```kotlin
fun main() {
    println(balanceAfter(5, listOf(-8, 4))) // 4
}
```
