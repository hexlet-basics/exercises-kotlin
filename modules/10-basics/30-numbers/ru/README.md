В этом уроке мы изучим арифметические операции и преобразования числовых типов. Сравним целочисленное деление с делением дробных чисел. Мы научимся выбирать тип операндов до вычисления результата и явно преобразовывать числа.

Оператор выполняет действие над значениями, которые называются операндами. Для чисел Kotlin поддерживает сложение `+`, вычитание `-`, умножение `*`, деление `/` и остаток `%`. Типы операндов влияют на результат, поэтому одинаковая математическая запись может дать разные значения.

Умножение, деление и остаток выполняются раньше сложения и вычитания. Скобки задают нужную группировку. Например, `(2 + 3) * 4` даёт `20`, а `2 + 3 * 4` даёт `14`.

## Целая и дробная части

Когда оба операнда имеют целочисленный тип, `/` отбрасывает дробную часть в направлении нуля. Оператор `%` возвращает остаток. Эти две операции удобны, когда нужно разбить количество на полные группы и остаток.

Допустим, отчёт хранит продолжительность записи в минутах. Для отображения мы хотим получить полные часы и оставшиеся минуты.

```kotlin
fun main() {
    val minutes = 137
    val hours = minutes / 60
    val remainder = minutes % 60

    println(hours) // 2
    println(remainder) // 17
}
```

В этом примере `137 / 60` вычисляет число полных часов, а `137 % 60` сохраняет оставшиеся минуты. Если требуется продолжительность в дробных часах, хотя бы один операнд должен быть дробным уже в момент деления.

Для другого отчёта нужно вычислить среднее число участников на встречу. Мы знаем общее количество посещений и встреч, но целое среднее потеряет часть информации.

```kotlin
fun main() {
    val visits = 17
    val meetings = 4

    val exactAverage = visits.toDouble() / meetings
    val truncatedAverage = (visits / meetings).toDouble()

    println(exactAverage) // 4.25
    println(truncatedAverage) // 4.0
}
```

Здесь `visits.toDouble()` превращает `17` в `17.0` до операции `/`. Вторая формула сначала выполняет целочисленное деление и получает `4`, поэтому последующее преобразование уже не возвращает потерянную дробную часть.

## Совместимость типов

Kotlin требует явного преобразования при присваивании значения другого числового типа. Если `count` имеет тип `Int`, запись `val wide: Long = count` не скомпилируется. Подходящее преобразование записывается как `count.toLong()`. Оно возвращает новое значение и оставляет `count` без изменений.

У результата арифметического выражения действуют правила самих операторов. Например, `2 + 0.5` даёт `Double` со значением `2.5`. Поэтому следует различать арифметику со смешанными операндами и присваивание отдельного значения переменной другого типа.

Дробное значение тоже можно преобразовать в целое. Вызов `8.9.toInt()` возвращает `8`, а `(-8.9).toInt()` возвращает `-8`. Это усечение к нулю. Для округления до ближайшего целого нужны другие операции, поэтому `toInt()` нельзя считать округлением.

## Литералы и диапазон

Суффикс `L` задаёт литерал `Long`, например `3_000_000_000L`. Подчёркивания помогают читать число и не меняют его значение. Литерал с десятичной точкой, например `2.5`, по умолчанию имеет тип `Double`.

Целочисленный тип имеет ограниченный диапазон. При вычислениях следует выбирать `Long`, если результат может выйти за диапазон `Int`, и преобразовывать операнды до операции. Запись `large.toLong() * 1000` выполняет умножение как `Long`, а преобразование уже переполненного результата не исправляет вычисление.
