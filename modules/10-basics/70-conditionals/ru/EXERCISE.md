Реализуйте функцию `deliveryLabel(weight: Int, express: Boolean): String`, которая выбирает способ доставки по весу посылки и запросу срочной доставки. Вес передаётся в целых килограммах.

Правила проверяются в следующем порядке. Верните результат первого подходящего правила.

- Если `weight` меньше либо равен нулю, верните `"invalid"`.
- Если запрошена срочная доставка (`express` равно `true`) и вес не превышает `5`, верните `"express"`.
- Если вес не превышает `20`, верните `"standard"`.
- Для остальных посылок верните `"cargo"`.

Используйте `when` без аргумента. Неподходящий для срочной доставки вес не делает посылку ошибочной, поэтому такая посылка проверяется по оставшимся правилам.

```kotlin
fun main() {
    println(deliveryLabel(0, true)) // invalid
    println(deliveryLabel(5, true)) // express
    println(deliveryLabel(6, true)) // standard
    println(deliveryLabel(21, false)) // cargo
}
```
