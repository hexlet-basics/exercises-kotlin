В этом уроке мы изучим условия как выражения Kotlin. Разберём сравнения, логические операции и выбор результата через `if` и `when`. Мы научимся задавать порядок проверок и завершать функцию при выполнении отдельного условия.

Условие вычисляет логическое значение `Boolean`. На его основе программа выбирает действие или результат. В Kotlin `if` и `when` можно использовать как выражения, поэтому выбранное значение разрешено сразу сохранить или вернуть из функции.

Равенство записывается как `==`, неравенство как `!=`. Для чисел также доступны `<`, `<=`, `>` и `>=`. Например, `"open" == "open"` даёт `true`, а `8 < 3` даёт `false`. Один знак `=` служит присваиванию и не проверяет равенство.

## Выбор результата через if

Представим, что сервис выдаёт число доступных попыток. При отрицательном остатке пользователю нужно показывать ноль. Мы выберем одно из двух чисел и вернём его как результат.

```kotlin
fun visibleAttempts(remaining: Int): Int {
    val visible = if (remaining < 0) 0 else remaining
    return visible
}

fun main() {
    println(visibleAttempts(-3)) // 0
    println(visibleAttempts(4)) // 4
}
```

В этом примере `if` вычисляет условие `remaining < 0`. Для отрицательного значения результатом становится `0`, для остальных значений результатом становится `remaining`. Обе ветки дают `Int`, поэтому переменная `visible` тоже имеет тип `Int`.

Если мы используем результат `if`, ветка `else` обязательна. Вычисление должно дать значение при любом исходе условия. Для нескольких проверок можно продолжить цепочку через `else if`.

## Логические операции

Оператор `&&` требует истинности обоих условий, `||` требует хотя бы одного истинного условия. `!` меняет логическое значение на противоположное. Например, `age >= 18 && hasTicket` проверяет сразу возраст и наличие билета.

Вычисление `&&` прекращается, когда левое условие ложно, а вычисление `||` прекращается, когда левое условие истинно. Такой порядок называется коротким замыканием. Например, в выражении `count != 0 && total / count > 5` правая часть выполняется только при ненулевом `count`, поэтому деление на ноль здесь не произойдёт.

Для явной группировки условий подходят скобки. Запись `isOwner || (isMember && isOpen)` разрешает действие владельцу либо участнику открытой группы. Понятное имя логической переменной позволяет читать условие без сравнения с `true`.

## Несколько вариантов через when

`when` проверяет ветки сверху вниз и выбирает первую подходящую. После стрелки `->` записывается результат или блок действий. `else` описывает случай, для которого другие ветки не подошли.

Допустим, программа переводит короткий код состояния в подпись. Для известных кодов нужны специальные названия, для остальных одно общее сообщение.

```kotlin
fun statusTitle(code: String): String =
    when (code) {
        "new" -> "Created"
        "done" -> "Completed"
        else -> "Unknown"
    }

fun main() {
    println(statusTitle("done")) // Completed
    println(statusTitle("paused")) // Unknown
}
```

Здесь `when (code)` сравнивает значение `code` с вариантами `"new"` и `"done"`. Ветка `else` обеспечивает результат для любой другой строки. Вызов `statusTitle("done")` выбирает вторую ветку и возвращает `"Completed"`.

Когда условия проверяют разные свойства входа, аргумент в скобках не нужен. Допустим, сообщение о температуре зависит от нескольких числовых границ.

```kotlin
fun temperatureTitle(temperature: Int): String =
    when {
        temperature < 0 -> "Freezing"
        temperature < 20 -> "Cool"
        else -> "Warm"
    }
```

В этом коде отрицательная температура подходит сразу под две проверки, но выбирается первая. До второй ветки доходят только значения от `0` до `19`. Перестановка этих веток изменила бы результат для отрицательных чисел.

## Ранний возврат

Отдельную проверку иногда удобнее выполнить перед основным вычислением. `return` сразу завершает функцию, поэтому код после него в выбранной ветке не выполняется.

Например, вычисление целой доли можно защитить договорённостью о результате при нулевом делителе. В этом примере функция возвращает `0`, если передан `count = 0`.

```kotlin
fun wholeShare(
    total: Int,
    count: Int,
): Int {
    if (count == 0) {
        return 0
    }
    return total / count
}
```

В этом примере после проверки остаётся только ненулевой `count`. Выбранная договорённость о нуле относится к этой функции. Позже мы разберём способы явно обозначать отсутствие результата и сообщать об ошибочных входах.
