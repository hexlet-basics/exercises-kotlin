В этом уроке мы изучим объявление функций с параметрами и результатом. Разберём типы в сигнатуре, возврат значения и тело в виде выражения. Мы научимся отделять вычисление от вывода и использовать результат функции в другом выражении.

Функция получает входные данные через параметры и выполняет заданную операцию. Её объявление описывает, какие значения разрешено передать и какой результат получит вызывающий код. Компилятор проверяет вызовы по этому контракту.

Объявление начинается с `fun`, затем идут имя и параметры в круглых скобках. Для каждого параметра мы указываем тип после двоеточия. Тип результата записывается после закрывающей скобки, а тело функции располагается в фигурных скобках.

## Возвращаемое значение

Представим, что программа рассчитывает площадь прямоугольной этикетки. Площадь потребуется и для отчёта, и для расчёта расхода материала. Поэтому функция вернёт число, которое вызывающий код сможет использовать дальше.

```kotlin
fun rectangleArea(
    width: Int,
    height: Int,
): Int {
    val area = width * height
    return area
}

fun main() {
    val small = rectangleArea(3, 5)
    val large = rectangleArea(8, 4)

    println(small + large) // 47
}
```

В этом примере `width` и `height` получают значения отдельно при каждом вызове. Локальная переменная `area` существует только внутри вызова. `return area` завершает функцию и передаёт вычисленное число вызывающему коду. В `main` результаты `15` и `32` сохраняются под разными именами и складываются.

Параметры внутри функции доступны только для чтения. Запись `width = 10` внутри `rectangleArea` недопустима. Для промежуточных изменений мы можем объявить собственную локальную переменную через `var`.

## Тело в виде выражения

Когда функция вычисляет одно выражение, Kotlin позволяет записать его после знака `=`. Такое объявление не требует `return`, а тип результата компилятор может вывести из самого выражения.

Допустим, калькулятор переводит расстояние из километров в метры. Для этой операции достаточно одного умножения.

```kotlin
fun kilometersToMeters(kilometers: Double): Double = kilometers * 1000

fun main() {
    val first = kilometersToMeters(1.2)
    val second = kilometersToMeters(0.05)

    println(first) // 1200.0
    println(second) // 50.0
}
```

В этом коде всё тело `kilometersToMeters` находится справа от `=`. Тип `Double` после параметров можно опустить, потому что умножение `Double` на целое число даёт `Double`. Явная запись типа всё равно помогает увидеть контракт без чтения формулы.

У функции с телом в фигурных скобках результат другого типа, кроме `Unit`, требуется указать явно. Компилятор не выводит такой тип по отдельным `return` внутри блока. Например, объявление `rectangleArea` сохраняет `: Int`.

## Вывод и Unit

Печать в консоль и возвращаемое значение решают разные задачи. Когда функция вызывает `println`, текст появляется в выводе программы. Когда она выполняет `return`, значение получает код, который её вызвал.

Функция, предназначенная только для действия, может иметь результат `Unit`. Например, короткая функция печати не предоставляет вызывающему коду полезного вычисленного значения.

```kotlin
fun printTitle(title: String) {
    println("[$title]")
}

fun main() {
    printTitle("Report") // [Report]
}
```

Здесь `printTitle` получает строку и печатает её в квадратных скобках. Аннотацию `: Unit` разрешено опустить. У `main` из первых примеров такой же тип результата. Для функции вычисления мы, напротив, выбираем конкретный тип и возвращаем значение, чтобы дальше его можно было проверить, сохранить или передать другой функции.
