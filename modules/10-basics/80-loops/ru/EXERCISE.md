Реализуйте функцию `firstMultiple(start: Int, endInclusive: Int, divisor: Int): Int`. Она возвращает первое число в возрастающем диапазоне от `start` до `endInclusive` включительно, которое делится на `divisor` без остатка.

Если подходящих чисел нет, верните `-1`. Если `start` больше `endInclusive`, диапазон пуст и результат тоже равен `-1`. Все границы неотрицательны и не превышают `1000`. Делитель находится в пределах от `1` до `1000`.

Используйте цикл и завершайте поиск после первого совпадения. Ноль делится без остатка на любой допустимый делитель.

```kotlin
fun main() {
    println(firstMultiple(5, 15, 4)) // 8
    println(firstMultiple(10, 12, 4)) // 12
    println(firstMultiple(10, 11, 4)) // -1
    println(firstMultiple(0, 8, 7)) // 0
}
```
