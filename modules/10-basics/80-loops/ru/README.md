В этом уроке мы изучим циклы и числовые диапазоны Kotlin. Разберём повторение по условию, обход заданных границ и управление итерациями. Мы научимся выбирать форму цикла и останавливать обработку после нужного результата.

Цикл повторяет блок кода. `while` проверяет условие перед каждой итерацией, `do/while` проверяет его после блока. `for` получает очередное значение из заданного диапазона и выполняет блок для каждого такого значения.

Итерацией называют одно выполнение тела цикла. Для цикла по условию алгоритм должен менять данные так, чтобы в нужный момент условие стало ложным. Иначе повторение продолжится без остановки.

## Циклы по условию

Представим, что мы удваиваем вместимость буфера, пока её не хватит для заданного числа элементов. Заранее число удвоений неизвестно, зато известна проверка достаточной вместимости.

```kotlin
fun bufferCapacity(required: Int): Int {
    var capacity = 1
    while (capacity < required) {
        capacity = capacity * 2
    }
    return capacity
}

fun main() {
    println(bufferCapacity(6)) // 8
    println(bufferCapacity(1)) // 1
}
```

В этом примере для `required = 6` переменная `capacity` последовательно получает `1`, `2`, `4` и `8`. Перед следующей итерацией условие `8 < 6` ложно, поэтому функция возвращает `8`. Для `required = 1` тело не выполняется ни разу.

У `do/while` тело выполняется хотя бы один раз. Например, в демонстрационном счётчике мы сначала печатаем значение, затем проверяем, осталось ли что печатать.

```kotlin
fun main() {
    var remaining = 2
    do {
        println(remaining)
        remaining = remaining - 1
    } while (remaining > 0)
}
```

Здесь программа выводит `2` и `1` на отдельных строках. Если начальное значение заменить на `0`, первая итерация всё равно напечатает `0`. Этот порядок отличает `do/while` от проверки в начале `while`.

## Диапазоны и for

Запись `a..b` включает обе границы. Запись `a..<b` исключает правую границу. Диапазон сам описывает значения, а `for` выполняет тело с каждым значением по порядку. Переменная цикла доступна только внутри его тела и получает значение автоматически.

Допустим, программа печатает номера трёх подготовленных страниц. Для второго отчёта правая граница уже обозначает первый номер за пределами набора.

```kotlin
fun main() {
    for (page in 3..5) {
        println(page)
    }
    for (page in 3..<6) {
        println(page)
    }
}
```

В этом коде оба цикла печатают `3`, `4` и `5`. Во втором цикле число `6` в обход не входит. Возрастающий диапазон `5..3` пуст, поэтому для него тело цикла не выполнится.

Для обратного порядка используется `downTo`, для шага используется `step` с положительным числом. Например, `6 downTo 2 step 2` задаёт числа `6`, `4`, `2`. Запись `1..6 step 2` задаёт `1`, `3`, `5`, потому что следующий шаг уже выходит за границу.

Оператор `in` также проверяет принадлежность диапазону. Выражение `age in 18..65` возвращает `Boolean` и позволяет использовать диапазон внутри условия.

## Пропуск и остановка

`continue` пропускает оставшуюся часть текущей итерации. `break` завершает ближайший цикл. Если поиск находится внутри функции, `return` завершает всю функцию и одновременно возвращает найденное значение.

Предположим, для небольшого отчёта нужны нечётные номера до первого номера больше пяти. Мы пропустим чётные значения, а верхнее ограничение обработаем остановкой.

```kotlin
fun main() {
    for (number in 1..10) {
        if (number > 5) {
            break
        }
        if (number % 2 == 0) {
            continue
        }
        println(number)
    }
}
```

В этом примере программа печатает `1`, `3`, `5`. Для `2` и `4` выполняется `continue`, поэтому до печати они не доходят. При значении `6` срабатывает `break`, и оставшиеся числа уже не рассматриваются. Проверки записаны в порядке, соответствующем правилу обработки.

При раннем `return` из функции код после цикла может описывать отсутствие найденного результата. Для отдельной числовой задачи мы вправе заранее договориться о специальном числе, которое не встречается среди допустимых результатов. Дальше в курсе мы освоим nullable-типы и сможем выражать отсутствие значения через систему типов.
