В этом уроке мы изучим объявление переменных и базовые типы Kotlin. Разберём вывод типа, явную аннотацию и область видимости имени. Мы научимся выбирать между `val` и `var` и сохранять значение до его изменения.

Переменная связывает имя с данными определённого типа. Тип ограничивает значения, которые разрешено записывать под этим именем. Kotlin проверяет это ограничение при компиляции, даже когда мы не написали тип явно.

Для объявления есть два ключевых слова. `val` разрешает присвоить значение один раз, `var` разрешает последующие присваивания. Обычно мы начинаем с `val` и выбираем `var`, когда алгоритм действительно меняет значение.

## Сохранение и изменение значения

Представим, что счётчик хранит число свободных мест. Нам нужно уменьшить остаток и сохранить начальное число для отчёта. Мы дадим исходному значению отдельное имя до изменения счётчика.

```kotlin
fun main() {
    var available = 18
    val initial = available
    available = 14

    println(initial) // 18
    println(available) // 14
}
```

В этом примере `initial` получает число `18` во время своего объявления. Последующее присваивание меняет только `available`. Имя `initial` продолжает хранить прежнее число. Присвоить ему новое число не получится, потому что мы объявили его через `val`.

Запрет нового присваивания относится к самой переменной. Когда мы начнём работать с коллекциями, отдельно разберём, при каких условиях может меняться содержимое значения, доступного через `val`.

## Вывод типа и аннотация

Компилятор умеет определять тип по начальному значению. В записи `val count = 18` литерал целого числа задаёт тип `Int`. Явная аннотация после имени нужна, когда мы хотим указать тип непосредственно или сделать его видимым читателю.

Допустим, программа хранит несколько полей карточки билета. У каждого поля своё назначение, поэтому мы выберем подходящие типы.

```kotlin
fun main() {
    val title: String = "Workshop"
    val seats: Int = 18
    val visitorId: Long = 4000000000L
    val price: Double = 12.5
    val isOpen: Boolean = true
    val row: Char = 'B'

    println(title)
    println(seats)
    println(visitorId)
    println(price)
    println(isOpen)
    println(row)
}
```

В этом коде `String` хранит текст в двойных кавычках. Целое число `seats` имеет тип `Int`, а литерал с суффиксом `L` задаёт `Long` с большим диапазоном. Для дробного числа используется `Double`, для `true` и `false` используется `Boolean`. Одинарные кавычки задают значение `Char`, например одну латинскую букву.

Если убрать аннотации в примере, компилятор выведет те же типы из литералов. Вывод типа не делает переменную способной принимать любые данные. После `var seats = 18` присваивание `seats = "many"` отвергается, потому что строка несовместима с `Int`.

## Область видимости

Область видимости определяет, где доступно имя. Локальная переменная внутри фигурных скобок видна после своего объявления до конца соответствующего блока. В соседней функции это имя само по себе не появляется.

В примере со счётчиком оба имени объявлены внутри `main`, поэтому последующие вызовы `println` могут к ним обратиться. Имя следует объявлять рядом с местом использования и называть по смыслу значения. Kotlin различает регистр, поэтому `available` и `Available` обозначают разные имена.
