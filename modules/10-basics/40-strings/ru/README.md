В этом уроке мы изучим строки и строковые шаблоны Kotlin. Разберём получение длины, доступ по индексу и преобразования текста. Мы научимся собирать сообщения из значений и учитывать границы строковых операций.

Строка хранит последовательность текста. В Kotlin значение `String` неизменяемо, поэтому операции преобразования возвращают новую строку. Чтобы использовать результат, мы сохраняем его в переменной или передаём в следующую операцию.

Свойство `length` сообщает длину, а квадратные скобки обращаются к элементу по индексу. Индексы начинаются с нуля. Для непустой строки последний допустимый индекс равен `length - 1`. Выход за допустимые границы приводит к ошибке выполнения.

## Подготовка текста

Представим, что приложение получает код помещения из текстового поля. Пользователь может добавить пробелы по краям или выбрать другой регистр букв. Для поиска мы хотим подготовить единый вариант записи.

```kotlin
fun main() {
    val input = "  Room-A7  "
    val cleaned = input.trim()
    val code = cleaned.lowercase()

    println(code) // room-a7
    println(input.length) // 11
    println(code.length) // 7
}
```

В этом примере `trim()` убирает пробельные символы по краям, а `lowercase()` возвращает вариант в нижнем регистре. Строка `input` сохраняет исходный текст. Мы также можем записать цепочку `input.trim().lowercase()`, потому что результат первого вызова становится значением для второго.

Пробелы внутри текста `trim()` сохраняет. Например, `"  Room A7  ".trim()` даёт `"Room A7"`. Это позволяет очищать края, сохраняя разделение слов.

## Строковые шаблоны

Шаблон подставляет значения непосредственно в строковый литерал. Для имени достаточно `$name`. Если требуется выражение, свойство или граница имени, используются фигурные скобки `${...}`.

Допустим, программа формирует короткую карточку файла. У нас есть имя и размер, а в сообщении требуется показать размер после добавления служебного заголовка.

```kotlin
fun main() {
    val name = "notes.txt"
    val size = 240
    val message = "File $name uses ${size + 16} bytes"

    println(message) // File notes.txt uses 256 bytes
    println("${name.length} code units") // 9 code units
}
```

Здесь `$name` подставляет строку, а `${size + 16}` сначала вычисляет сумму. Выражение `${name.length}` читает свойство строки. Если к имени вплотную примыкают буквы, скобки показывают, где заканчивается имя, например `"${size}B"`.

Для перевода строки в обычном литерале используется `\n`, для табуляции `\t`. Кавычка внутри строки записывается как `\"`, обратная косая черта как `\\`, а буквальный знак доллара как `\$`.

## Индексы и фрагменты

Индекс позволяет получить значение `Char`. Вызов `substring(startIndex, endIndex)` возвращает часть строки от начального индекса включительно до конечного исключительно. Такой контракт удобно читать как полуинтервал границ.

Предположим, внешняя система присылает код `AB-908`, а нам нужны буквенная часть и первая цифра. Формат фиксирован и состоит из ASCII-символов.

```kotlin
fun main() {
    val code = "AB-908"

    println(code[3]) // 9
    println(code.substring(0, 2)) // AB
    println(code.substring(3)) // 908
}
```

В этом коде индекс `3` указывает на первую цифру после дефиса. Граница `2` в первом `substring` исключена, поэтому дефис не попадает в результат. Если конечную границу не передать, фрагмент продолжается до конца строки.

Длина и индексы Kotlin/JVM измеряются кодовыми единицами UTF-16. Один `Char` занимает одну такую единицу, но видимый символ может занимать несколько единиц. Например, `"🥦".length` равно `2`. Поэтому индексные примеры и упражнение используют ASCII, где каждая буква, цифра и знак занимают одну единицу.
