Реализуйте класс `TicketBatch(total: Int)` для остатка билетов. Начальный остаток может быть нулевым, но отрицательное значение должно приводить к `IllegalArgumentException` при создании экземпляра. Проверку выполните через `require` внутри `init`.

Свойство `remaining` должно быть доступно для чтения извне и изменяться только внутри класса. Метод `take(count: Int)` сначала проверяет через `require`, что запрошено положительное число билетов. Затем через `check` проверяет достаточность текущего остатка. Недостаток билетов должен приводить к `IllegalStateException`. При успехе метод уменьшает остаток на `count`. При любой ошибке остаток сохраняется.

Добавьте к проверкам непустые сообщения, поясняющие причину отказа. Все числа по абсолютной величине не превышают `100000`.

```kotlin
fun main() {
    val batch = TicketBatch(5)
    batch.take(2)
    println(batch.remaining) // 3
}
```
