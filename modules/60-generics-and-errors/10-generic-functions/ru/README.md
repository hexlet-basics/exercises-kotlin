В этом уроке мы изучим объявление обобщённых функций. Разберём параметр типа, вывод его значения и ограничение `T : Any`. Научимся сохранять связь между типами аргументов и результата функции.

В типе `List<String>` запись `String` задаёт тип элементов. Операции над списком часто сохраняют эту связь без знания конкретного типа. Например, получение элемента списка строк возвращает строку, а получение элемента списка чисел возвращает число. Собственная функция тоже может работать с типом, который будет выбран при вызове.

Предположим, нам нужно брать первый элемент списка, если он существует. Объявим параметр типа `T` перед именем функции.

```kotlin
fun <T> firstValue(values: List<T>): T? = values.getOrNull(0)

fun main() {
    val word: String? = firstValue(listOf("red", "blue"))
    val number: Int? = firstValue(listOf(4, 9))
    println(word) // red
    println(number) // 4
}
```

`T` обозначает один и тот же выбранный тип во всей сигнатуре. При первом вызове компилятор подставляет `String`, а при втором `Int`. Функция не превращает значение в `Any`, поэтому вызывающий код сохраняет сведения о типе результата.

Обычно компилятор выводит аргумент типа из входных значений. Его также можно указать явно, например `firstValue<String>(listOf())`. У пустого списка нет элементов, по которым можно выбрать тип, поэтому такая запись помогает задать ожидаемый результат.

## Ограничение параметра типа

Внутри обобщённой функции доступны операции, которые разрешены для любого допустимого `T`. Если тип ничем не ограничен, он может быть и nullable. Например, `List<String?>` допускает элемент `null`.

Для поиска это создаёт неоднозначность. Результат `null` может означать отсутствие совпадения или найденный элемент, который сам равен `null`. Ограничение `T : Any` исключает nullable-типы из аргументов типа.

```kotlin
fun <T : Any> firstAccepted(
    values: List<T>,
    accepts: (T) -> Boolean,
): T? {
    for (value in values) {
        if (accepts(value)) return value
    }
    return null
}

fun main() {
    println(firstAccepted(listOf("a", "long")) { it.length > 2 }) // long
    println(firstAccepted(listOf(2, 4)) { it > 10 }) // null
}
```

Здесь `T?` в результате добавляет возможность отсутствия к типу элемента, который сам не допускает `null`. Предикат получает значение типа `T`, а не `Any`, поэтому при вызове со строками в его теле доступно свойство `length`. Объявление одной функции проверяется для всех разрешённых типов, а каждый вызов сохраняет собственную конкретную связь типов.
